# Random Picker

候補を1行ずつ貼り付けて、抽選・順番決め・チーム分け・ルーレットをすぐ使える、ローカル処理の単一HTMLツールです。

## 特徴

- 1件または複数件をランダム抽選
- 当選済み候補を次回から除外
- 候補全体をランダムな順番に並び替え
- チーム数 / 1チームの人数のどちらからでも、人数差が最大1人になるチーム分け
- Canvasによるルーレット表示
- 抽選履歴、モード別の結果コピー、共有、全画面表示
- 順番を大画面で1人ずつ発表
- 候補リストを名前付きで複数保存
- Excelなど複数列の貼り付け時に候補列を選択
- 重複候補を別候補として保持
- 空行削除・空白整理・重複削除
- 候補と設定を端末内へ自動保存
- 日本語 / English 切替
- 外部ライブラリなし、実行時通信なし

抽選にはブラウザー標準の `crypto.getRandomValues()` を使用し、modulo biasを避けるためrejection samplingを行っています。

## 使い方

1. 候補を1行に1つずつ入力または貼り付けます。
2. `抽選` / `順番` / `チーム` / `ルーレット` を選びます。
3. 選択したモード専用の設定を必要に応じて調整します。
4. 実行ボタンを押します。
5. 結果をコピー・共有・全画面表示したり、そのまま再抽選できます。

## プライバシー

候補、設定、抽選処理はブラウザー内だけで完結します。このアプリから候補をサーバーへ送信する処理はありません。現在の候補と設定は、利用可能な場合のみ `localStorage` に保存されます。

## 対応ブラウザー / 端末

現在の安定版 Chromium、Firefox、Safari のデスクトップ・スマートフォンを対象にしています。`dist/index.html` は `file://` から直接開けます。

## 制限

- 候補は最大10,000件です。
- ルーレット表示は最大200件です。大量候補は通常の抽選を使ってください。
- v1.0.0では重み付き抽選、クラウド保存、CSVファイル読込、Google Sheets連携には対応していません。
- ブラウザーのサイトデータを削除すると、自動保存した候補も消える場合があります。

## 単一HTML / オフライン

リリース成果物は以下の2種類です。

- `dist/index.html` — 読みやすい完全内包版
- `dist/index.self-extract.html` — gzip自己展開版

どちらも実行時に外部CDNやAPIへ接続しません。

## 開発 / ビルド

Windowsでリポジトリ直下の以下を実行します。

```bat
build-standalone.bat
```

検証のみ行う場合:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-repository.ps1
```

生成された `dist/index.html` / `dist/index.self-extract.html` は直接編集せず、`src/index.template.html` を変更して再ビルドします。
